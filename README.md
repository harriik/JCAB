# JCAB: Java Conversational Assessment and Personalized Feedback

**Research Title:**  
"An Adaptive Personalized Feedback Framework for Enhancing Multi-Agent Large Language Model-Based Conversational Assessment in Education"

**Status:** Preliminary Academic Research Prototype  
**Domain:** Java Programming  
**Dataset:** Synthetic Development Dataset  

---

## 1. Project Objective
JCAB is a preliminary academic research prototype designed to evaluate an adaptive, personalized feedback framework for MCA students learning Java programming. 

> [!WARNING]
> **Research Integrity Notice:** 
> This prototype currently uses a **Synthetic Development Dataset**. The prediction models and metrics generated by this prototype represent preliminary pipeline development and have **not** yet been validated by faculty or tested on real student data. The scores produced do not represent final research findings.

## 2. Research Scope & Limitations
- **Current Stage:** Pipeline Development and Prototype Testing.
- **Dataset:** Synthetic data used for building the preprocessing and ML pipeline.
- **Conversational Assessment:** Currently uses a controlled question bank to simulate follow-up interactions. Dynamic LLM generation of follow-up questions is a future planned integration.
- **Feedback Generation:** Currently utilizes a rule-based fallback logic using the ML outputs. Multi-Agent LLM integration for natural language feedback generation is planned for the next stage.

## 3. Architecture

The pipeline workflow is designed as follows:

```
Student
  ↓
Java Question
  ↓
Student Response
  ↓
Follow-up Interaction (Question Bank)
  ↓
Conversation Text
  ↓
Preprocessing
  ↓
Sentence-BERT (all-MiniLM-L6-v2)
  ↓
XGBoost ML Models (Score & Learner Level)
  ↓
Personalized Feedback (Rule-Based Fallback)
  ↓
Assessment Report (CSV)
```

## 4. Technologies
- **Python** (Core application logic)
- **Streamlit** (UI/UX for prototype demonstration)
- **Sentence-Transformers** (Semantic Embeddings)
- **XGBoost** (Preliminary ML predictions)
- **Scikit-Learn & Pandas** (Data handling)

## 5. How to Run

1. **Install dependencies:**
  It is highly recommended to use the exact pinned versions for model compatibility, particularly `xgboost==1.7.6`.
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Streamlit application:**
   ```bash
   streamlit run app.py
   ```

## 6. Future Work
- **Multi-Agent Architecture:** Implementing an LLM agent to dynamically generate follow-up questions based on the student's initial response.
- **LLM Feedback Generation:** Refactoring the current rule-based feedback module to use an LLM API for deep, personalized natural-language feedback.
- **Real Student Validation:** Collecting and benchmarking real student data with ground-truth teacher scores to validate the XGBoost models.
- **Final Evaluation:** Public dataset benchmarking and faculty evaluation of the feedback quality.
