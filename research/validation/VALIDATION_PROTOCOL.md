# JCAB Real Student Validation Protocol

## Objective
To evaluate the JCAB framework's personalized feedback generation when interacting with real MCA (Master of Computer Applications) students, contrasting performance against the synthetic development results.

## Protocol Steps
1. **Consent & Setup:** Participant reads the voluntary consent notice in the app. Participant enters an ID (can be anonymous) and selects "Java".
2. **Assessment Phase:** Participant answers conceptually-driven Java questions, first initially and then via a follow-up probe. Responses can be spoken or typed.
3. **LLM Processing:** The response is embedded via Sentence-BERT, scored via XGBoost, and feedback is generated by the Gemini Multi-Agent LLM pipeline.
4. **Feedback Review:** Participant reviews the personalized feedback and recommendations.
5. **Survey Phase:** Participant rates 5 usability and relevance metrics on a 1-5 scale and provides qualitative feedback.

## Ethical & Privacy Considerations
- Participation is strictly voluntary.
- No personally identifiable information (PII) other than a voluntary name/ID is collected.
- Raw interaction logs do not store audio recordings, only text transcripts.
- API Keys are not stored in the CSV exports.
