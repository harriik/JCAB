# Synthetic Validation Dataset

**SYNTHETIC/SIMULATED DATA — NOT REAL STUDENT VALIDATION**

Synthetic data was generated solely for development, pipeline testing, and demonstration. It is not evidence from human participants and must not be reported as real student validation.

## Contents

- `synthetic_student_validation_raw.csv`: Simulated assessment interactions.
- `synthetic_student_feedback_ratings.csv`: Simulated participant feedback and ratings.
- `plots/`: Charts illustrating the simulated distributions and rating results.

All records correspond to simulated participants (e.g. `SIM_P01` to `SIM_P20`) and were generated programmatically with a fixed random seed. No Gemini API calls were made to generate the feedback in this dataset.
